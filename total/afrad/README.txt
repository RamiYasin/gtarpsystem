# GTA RP Rank Inventory v4

الإدخال:
@name : المجموع : الرتبة

المجموع = السيناريوهات + السكربتات.

الحساب التراكمي:
إذا كان 200 والرتبة جندي:
200 - 45 = 155
155 - 45 = 110
110 - 60 = 50
50 أقل من 85، فيتوقف عند عريف.

الشروط الإضافية لا تخصم من المجموع. بعد الوصول الرقمي للرتبة، يفحص النظام شرطها:
- رقيب: مسؤول مركز العمليات + دخول قسم/الكلية/الشؤون الداخلية.
- رئيس رقباء: دورة الصاعقة + مسؤول مركز العمليات + دخول قسم/الكلية العسكرية.
إذا اكتملت الشروط يظهر "مؤهل"، وإلا "غير مؤهل" مع النواقص.
يمكن تفعيل الخانات مباشرة بجانب اسم العسكري، ويتغير الوضع فوراً.

المتطلبات المجمعة:
جندي 45
جندي اول 45
عريف 60
وكيل رقيب 85
رقيب 110
رقيب اول 125
رئيس رقباء 85


تحديث الحالة:
إذا وصل العسكري رقمياً إلى رتبة مثل رقيب، يظهر له "مؤهل" حتى لو كان ينقصه شرط إضافي.
يظهر أسفلها "الناقص: مسؤول مركز العمليات • دخول قسم/الكلية/الشؤون الداخلية".
أي أن "مؤهل" تعني أن متطلبات المجموع مكتملة، أما الدورات والأقسام فتظهر كنواقص منفصلة.

تم إصلاح زر تحليل القائمة وتحديث عداد المؤهلين والحساب التراكمي.

تصدير الديسكورد:
- زر "نسخ قائمة الديسكورد" ينسخ القائمة مباشرة للحافظة.
- زر "تحميل TXT" يحفظها كملف نصي.
الصيغة:
@name : المجموع : الرتبة المستحقة
وعند وجود شروط إضافية ناقصة:
@name : المجموع : الرتبة المستحقة - مؤهل (الناقص: ...)

تحديث v8:
- تمت إضافة رتبة ملازم بعد رئيس رقباء.
- للترقية إلى ملازم يجب إتمام 10 توظيف + 10 ملفات شؤون.
- أضيفت خانات عدد التوظيف وملفات الشؤون بجانب كل عسكري.
- عند الوصول رقمياً إلى ملازم، يظهر "مؤهل" مع النواقص إذا لم تكتمل 10/10.

v9:
الصيغة الجديدة:
@name : السيناريوهات : المجموع : الرتبة

مثال:
@mnykh : 100 : 541 : رئيس رقباء

عند الترقية من رئيس رقباء إلى ملازم:
- السيناريوهات >= 100
- التوظيف >= 10
- ملفات الشؤون >= 10
- دورة الصاعقة
إذا اكتمل شرط الـ100 سيناريو ولكن الشروط الأخرى ناقصة، تظهر الحالة "مؤهل" مع قائمة النواقص.
